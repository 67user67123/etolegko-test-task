# тестовое

Написать скрипт-замерятель скорости интернета со своего компьютера.

Он должен принимать адрес, куда стучаться (какая-нибудь тяжелая картинка) , запускать последовательно 10 запросов к этому адресу, дожидаться ответа, вычислять среднее время запроса, объем скачанных данных и печатать в консоли скорость мб/с.

## Решение

Консольный скрипт `speed_test.py`, Python 3.10 или новее. Внешние зависимости не нужны.

### Запуск

```console
python speed_test.py "https://example.com/large-image.jpg"
```

Замените пример на доступный HTTP(S) адрес большого файла. В Windows вместо
`python` также можно использовать `py -3`.

Необязательный параметр `--timeout` задаёт тайм-аут отдельной сетевой операции
в секундах (по умолчанию — 30). Это не ограничение общей длительности скачивания:

```console
python speed_test.py "https://example.com/large-image.jpg" --timeout 60
python speed_test.py --help
```

Скрипт выполняет **ровно 10 последовательных GET-запросов**. Следующий запрос
начинается только после полного чтения и закрытия предыдущего ответа. Данные
читаются блоками по 64 КиБ и не сохраняются на диск. Объём считается по фактически
прочитанным байтам; `Content-Length`, если он есть, служит проверкой полноты ответа.
Пустой ответ или обнаруженный обрыв передачи считается ошибкой.

Для каждого запроса `time.perf_counter()` измеряет время от начала обращения до
конца скачивания, включая установку соединения и HTTP-перенаправления. Заголовки
просят сервер и промежуточные кеши отдавать свежий ответ без сжатия.

### Результат

Пример вывода (числа условные):

```text
Выполнено запросов: 10
Среднее время запроса: 0.800 с
Скачано данных: 100000000 байт (100.000 МБ)
Суммарное время запросов: 8.000 с
Скорость: 12.500 МБ/с (100.000 Мбит/с)
```

- Среднее время запроса = сумма времени всех запросов / 10.
- Объём = сумма размеров десяти полностью скачанных ответов.
- Скорость в МБ/с = общий объём в байтах / суммарное время в секундах / 1 000 000.
- Скорость в Мбит/с = скорость в МБ/с × 8.

Используются десятичные единицы: 1 МБ = 1 000 000 байт. Результат показывает
скорость скачивания с выбранного сервера с учётом задержек сети и сервера;
он может отличаться от максимальной скорости подключения по тарифу.
Выбранный файл будет скачан десять раз: файл размером 10 МБ потребует около 100 МБ
входящего трафика, не считая служебных данных протоколов.

При неверном URL, HTTP-ошибке, сетевом сбое или тайм-ауте скрипт выводит причину
в stderr и завершается с кодом 1 без итогового результата. Прерывание через
Ctrl+C возвращает код 130.

### Проверка

```console
python -m unittest discover -s tests -v
```

Тесты используют локальный HTTP-сервер и не требуют доступа в интернет.
